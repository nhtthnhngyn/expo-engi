# Changelog — protocol-design.default

## v1 — 2026-01-09

Initial publication. The first format built on the engine, and one half of the genericity
checkpoint: it renders through the same renderer binary as `report-writing.consort` with no
renderer code differing between them.

- Free tier: a protocol draft is core workflow, not a paid export.
- No checklist styles and no external numbering — deliberately, so the pairing with CONSORT
  exercises a genuinely different config shape.
